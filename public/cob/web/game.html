🎯 Логика работы способностей

Базовые эффекты:

  • {Damage N} - Накапливает N урона у игрока. Игрок должен выбрать цель вручную
  • {Heal N} - Мгновенно восстанавливает N HP игроку
  • {Blessing N} - Дает N душ для покупок в этом ходу
  • {Draw N} - Мгновенно добирает N карт в руку
  • {Poison N} - Накладывает N яда на противника (действует в начале хода)
  • {Bleed N} - Накладывает N кровотечения на противника (действует в начале хода)

Управляющие эффекты:

  • {Stun N} - Заставляет противника сбросить N карт из руки
  • {Discard N} - Заставляет себя сбросить N карт из руки
  • {Trash N} - Уничтожает N стартовых карт навсегда
  • {Burn N} - СТОИМОСТЬ: тратит N душ. Если недостаточно - эффект не срабатывает

Торговые эффекты:

  • {Acquire} - Получить любую карту из рынка бесплатно
  • {Steal} - Украсть карту из руки или сброса противника
  • {Trash Trade Row X} - Уничтожить X карт из рынка

Условные эффекты:

  • Chain - Срабатывает только если в этом ходу сыграна карта нужного цвета
  • TO - "Если условие ТО эффект". Проверяет условие перед активацией
  • OR - Выбор одной из альтернатив (автоматический для ИИ)

🛡️ Attire карты

  • Def_Y_Text: Защищают игрока, поглощая урон
  • Def_N_Text: Отдельные цели с собственным HP

🔗 Chain эффекты

Активируются только при наличии карт соответствующего цвета, сыгранных в этом же ходу

🎮 Фазы хода

  1. Начало хода: Применение статусных эффектов (яд, кровотечение)
  2. Основная фаза: Разыгрывание карт и активация эффектов
  3. Фаза покупок: Покупка карт за Души
  4. Конец хода: ⚠️ ВСЕ НЕИСПОЛЬЗОВАННЫЕ ДУШИ СГОРЯТ! Сброс руки и добор новых карт

✨ Важно про Души

Души НЕ накапливаются между ходами! Все неиспользованные Души исчезают в конце хода.
